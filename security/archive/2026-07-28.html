vBulletin 템플릿 엔진 인증 전 원격코드실행 결함(CVE-2026-61511), 공개 익스플로잇 등장
SSD Secure Disclosure가 7월 27일 vBulletin 6.2.1·6.1.6 이하 버전에서 방문자가 값을 조작해 PHP eval()까지 도달하는 인증 없는 원격코드실행 결함의 동작 익스플로잇을 공개했다. vBulletin은 이미 6월 말~7월 1일 사이 패치를 배포한 상태다.

왜 중요한가
결함은 vBulletin의 공개 라우트인 ajax/render/pagenav가 방문자가 넘긴 pagenav[pagenumber] 값을 {vb:math} 태그에 그대로 넣어 runMaths() 함수의 eval()에 전달하는 구조에서 발생한다. 필터가 알파벳은 막지만 숫자·괄호·연산자는 허용해, 문자 없이도 PHP 함수를 재구성하는 "phpfuck" 기법으로 임의 명령을 실행할 수 있다. vBulletin Cloud는 이미 패치가 적용됐고, 자체 호스팅 포럼도 6.2.2 업데이트나 해당 브랜치 패치를 적용하면 안전하다. 다만 패치가 나온 지 거의 한 달 만에 실동작 익스플로잇이 공개된 만큼, 인터넷에 노출된 채 업데이트를 미룬 자체 호스팅 vBulletin 포럼은 우선 점검이 필요하다. 아직 CISA KEV 목록에는 등재되지 않았고 실공격 사례도 확인되지 않았다.
